Scripts for using with ollama / python-ollama

- translate.py : script to translate subtitles, you will need python-ollama and python-srt. At the moment is all hardcoded ES->EN but with small changes it can translate from any language that the model supports it (around 50 IIRC), it will take the subtitle and take also in context the last 5 lines.
Its a bit rough, but it works.
